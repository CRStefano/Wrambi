# Wrambi
Wrambi joins things that usually live in separate apps:  - **a distraction‑free editor** in the spirit of Calmly Writer and iA Writer: a full‑window page, a structural formatting toolbar, autosave, Focus mode; - **a library of your own files**, in the folder you choose, with page previews, folders and reading states (unread, reading, read); - **notes anchored to the text.** Select a passage and press `Ctrl+M` (`⌘M` on a Mac): the passage turns red and opens like a footnote. Every note from every document is collected in one place, and can be exported or turned into real footnotes; - **citations from Zotero** (or any `.bib` / CSL JSON file), formatted author‑year in every export; - **a PDF editor that keeps the layout**: rewrite a line, add text, highlight, cover, insert images, rotate, reorder, delete and merge pages.  Your files stay where they are, in ordinary formats. Nothing is uploaded anywhere.
